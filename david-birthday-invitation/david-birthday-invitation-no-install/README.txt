DAVID BIRTHDAY INVITATION — NO INSTALL VERSION

HOW TO OPEN
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html.
4. The invitation opens directly in your browser.

No Node.js, npm, command prompt, or installation is required.

SAVING THE CHOICE
The selected date style is saved in the browser using localStorage. It will remain available when the same file is reopened on the same browser/device.

SHARING BETWEEN DEVICES
For a shareable link that works on another device, upload index.html to a static hosting service such as GitHub Pages, Netlify Drop, or Cloudflare Pages. No npm build is needed. Once hosted, the “Copy Shared Dashboard Link” button creates a URL containing the selected date style.
